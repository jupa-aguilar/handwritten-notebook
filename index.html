      Notebooks

        Archived

        Kept whole in your Drive — pages, transcriptions and review cards — and off every device until you bring one back.

          Check the transcription

          Vision reads handwriting well, not perfectly, and its mistakes are invisible — the transcript reads like something, so nothing looks wrong until a search comes up empty. A model reads the page back and points at words that can't be what the line means; the line in your own hand is shown with each one, and nothing changes until you say so.

          Review

          Questions drawn from your own pages. Each answer shows the handwriting it came from, so what you check yourself against is the notebook — not somebody's summary of it. With Drive sync set up, the cards and where each one has got to in its schedule travel between your devices.

          Worth remembering

          Progress

          How much help you needed

          Every answer ever recorded, split by how much help it took. Accuracy stays roughly flat by design — the scheduler keeps showing you what you are about to forget — so this is the number that moves: the same deck answered with less and less help. The chart below is where you see it move.

          Over time

          Cards that are fighting you

          Ranked by how much trouble they give, with the evidence beside each one. Rewrite asks for a new question about the same material, telling the model what went wrong with this one — its schedule starts over, because it becomes a different question.

          All pages

          Drag a page to reorder it. Click a page to open it, or tick the checkboxes to select several pages (shift-click, or hold on a touch screen, to tick a whole run at once) — they can then be downloaded (as a zip), replaced or deleted together, or dragged as one block. 🔁 swaps a page for an edited copy; replacing several pairs your files with the selected pages in name order — pick more files than you selected and the extras are inserted right after them.

          Google Cloud Vision API key

          Handwriting transcription uses Google Cloud Vision. Your key is stored only in this browser (localStorage) and is sent directly to Google — never to any other server. In Google Cloud Console: enable the Cloud Vision API, then create an API key under APIs & Services → Credentials. The first 1,000 pages/month are free.

          Sync across devices (optional)

          Keeps notebooks in sync through a hidden app folder in your own Google Drive. In the same Cloud Console: create an OAuth client ID of type Web application and add this site's address under Authorized JavaScript origins. Paste the client ID here, save, and sign in when prompted. Then use the same ID on every device. The Mac app also needs the client secret (plus http://127.0.0.1:17987 under Authorized redirect URIs) so it can stay signed in; browsers can leave it empty.

          Chat (optional)

          💬 Chat answers questions about the open notebook. With an OpenAI API key it uses gpt-5.6-luna: fast, but each message is billed and the transcribed pages are sent to OpenAI — set a spending limit on the key. Leave it empty to keep everything on this machine instead.

          Without a key, chat uses a model running locally via LM Studio: in its Developer tab, load a model, start the server and enable CORS. Leave the address empty for the default http://localhost:1234.

          Guía

          Empezar

          Sube fotos o escaneos de tus páginas con el ＋ de la barra de arriba. Se guardan en este dispositivo, no en un servidor: la app funciona sin conexión y tus apuntes no salen de aquí salvo que actives la sincronización.

          Para que la app pueda leer tu letra hace falta una clave de Google Cloud Vision en ⚙. Sin ella puedes leer y marcar páginas, pero no buscar dentro de ellas, ni preguntar al chat, ni hacer tarjetas de repaso — todo eso se apoya en la transcripción.

          Buscar

          La búsqueda mira dentro del texto transcrito de todas las páginas. Ignora mayúsculas y acentos, y una página aparece cuando contiene todas las palabras que escribiste, no la frase literal.

          Lo que la hace distinta: además de listarte las páginas, dibuja un recuadro sobre cada palabra encontrada, encima de tu letra.

          El resultado señalado sobre la propia página

          ⌘F lleva el cursor a la búsqueda desde cualquier sitio. Esc la limpia.

          Texto y ✨ Check

          Text abre la transcripción de la página que estás leyendo. Ahí vive ✨ Check, la revisión asistida.

          La máquina lee tu letra bien, pero no perfecto, y sus errores son invisibles: el texto parece decir algo, así que no notas nada hasta que una búsqueda no encuentra lo que sabes que escribiste. Con ✨ Check, un modelo relee la página y señala palabras que no pueden ser lo que la línea dice.

          Repaso

          Preguntas sacadas de tus propias páginas. Lo que las hace distintas de cualquier app de fichas: la respuesta te enseña el recorte de tu letra, así que lo que compruebas es tu cuaderno, no el resumen de alguien.

          1. Abre 🎯 Review y pulsa Generate cards. Se pide una vez por página, y solo por las que aún no tienen tarjetas — puedes parar a medias y seguir otro día.
          2. Start review empieza la sesión. espacio revela la respuesta.
          3. ¿No te sale? h sube un escalón cada vez: primero una pista escrita, que apunta sin decirlo, y luego Show the line, la línea de tu cuaderno con la respuesta tapada. Desde el primer escalón se retira Easy, que ya no sería honesto.
          4. Al revelar vuelve esa misma línea sin tapar, con la respuesta resaltada en su sitio, y debajo un aprendizaje: una frase que añade lo que la respuesta sola no dice. Sale de tu página, no de fuera.
          5. Califica con los botones, o con 1–4. Cada uno te dice cuándo volverá esa tarjeta.

          Fallar no castiga: devuelve la tarjeta dentro de la misma sesión
          • El número naranja sobre 🎯 es lo que te toca hoy. Sin número, no hay nada pendiente.
          • ¿Una pregunta mal hecha? Delete this card. ¿Una página entera que salió mal? Clear page N y genérala otra vez.
          • Add hints aparece si tienes tarjetas de antes de que existieran la pista y el aprendizaje: se los añade sin tocar lo que ya llevas repasado. Regenerar la página, en cambio, borraría su calendario.
          • Answer from options, en el mazo, cambia la sesión: en vez de recordar, eliges entre cuatro respuestas — y las incorrectas son respuestas tuyas de otras tarjetas, nunca inventadas. Elegir ya califica (aciertas Good, fallas Again), y las teclas 1–4 eligen. Es una rampa para arrancar: reconocer se recuerda peor que evocar, así que conviene apagarlo cuando el mazo deje de dar miedo.
          • Si en una página no hay respuestas que tengan que ver con la pregunta, los señuelos salen flojos y la correcta canta. Con el modo encendido aparece 🎲 Better options, que se los pide al modelo sólo para esas tarjetas y los guarda.
          • 📈 Progress lleva la cuenta de cuánta ayuda necesitaste. El acierto se mantiene plano a propósito —el programador te enseña justo lo que estás por olvidar—, así que lo que se mueve es el escalón: el mismo mazo respondido cada vez con menos ayuda. Ahí están también las tarjetas que te están ganando, con su expediente, y Rewrite, que pide una pregunta nueva sobre la misma materia contándole al modelo qué salió mal con la anterior.

          Las tarjetas y su calendario se sincronizan: lo que repases en el teléfono aparece repasado en el ordenador.

          Chat

          Pregunta sobre lo que hay escrito en el cuaderno. Responde a partir de las páginas transcritas, y cuando cita una, el número de página es un enlace que te lleva allí.

          Necesita un modelo: una clave de OpenAI en ⚙, o LM Studio corriendo en tu ordenador (gratis y sin salir de casa). Con la clave, cada mensaje cuesta unos céntimos y el gasto se ve dentro de ☁.

          Find on this page, arriba del panel, busca dentro de la transcripción que tienes delante — la caja de la barra superior contesta otra pregunta: qué páginas lo mencionan. El contador dice cuántas hay, enter salta a la siguiente (con shift, a la anterior) y el panel se desplaza hasta ella. La actual va en naranja; las demás quedan marcadas para que veas dónde caen.

          ¿Quieres preguntar por un párrafo concreto? Selecciónalo en 📖 Text y elige: 🎓 Explain this pide ahí mismo una explicación llana, con una analogía cotidiana y en tres párrafos, sin que escribas nada; 💬 Ask about this se queda esperando a que preguntes tú. En ambos casos el pasaje queda como una tarjetita sobre la caja de escribir, y todas tus preguntas se responden sobre él hasta que lo quites con la ✕. En el teléfono se selecciona manteniendo pulsado.

          Si no menciona ninguna página, responde sobre la que estás mirando. Las conversaciones se guardan por cuaderno, pero no se sincronizan.

          Sincronizar

          La copia y el traspaso entre aparatos van por tu propio Google Drive, en una carpeta oculta que solo esta app puede ver. Se configura con un ID de cliente en ⚙.

          • Viajan: los cuadernos, las páginas con su texto, los marcadores y las tarjetas de repaso.
          • No viajan: las conversaciones del chat y tus claves.

          Si editas en dos aparatos sin sincronizar entre medias, no se pierde nada: se mezclan página por página y gana la versión más reciente de cada una.

          Archivar un cuaderno

          El botón 📦 de 📚 guarda un cuaderno terminado en tu Drive y lo quita de este aparato y de los demás. No se borra nada: vuelve entero —páginas, transcripciones y tarjetas con su calendario de repaso— cuando pulses Restore en la lista de Archived.

          La copia local solo se suelta después de comprobar que todas las imágenes están arriba; si algo falla, el cuaderno se queda donde estaba. El 🗑️ rojo de esa lista sí es definitivo: borra el cuaderno de Drive y no queda copia en ningún sitio.

          Guardar y llevarte todo

          • Pages → 📄 PDF arma un PDF buscable: la imagen de tus páginas con el texto transcrito detrás, invisible, para que Vista Previa o Acrobat encuentren palabras dentro de tu letra.
          • Pages también deja seleccionar varias para descargarlas juntas, sustituirlas por una versión editada o borrarlas.
          • Desde 📚 puedes exportar un cuaderno entero a un archivo e importarlo en otro sitio.
