      Notebooks

        Check the transcription

        Vision reads handwriting well, not perfectly, and its mistakes are invisible — the transcript reads like something, so nothing looks wrong until a search comes up empty. A model reads the page back and points at words that can't be what the line means; the line in your own hand is shown with each one, and nothing changes until you say so.

        Review

        Questions drawn from your own pages. Each answer shows the handwriting it came from, so what you check yourself against is the notebook — not somebody's summary of it. Cards stay on this device; nothing about them is synced yet.

        All pages

        Drag a page to reorder it. Click a page to open it, or tick the checkboxes to select several pages (shift-click, or hold on a touch screen, to tick a whole run at once) — they can then be downloaded (as a zip), replaced or deleted together, or dragged as one block. 🔁 swaps a page for an edited copy; replacing several pairs your files with the selected pages in name order — pick more files than you selected and the extras are inserted right after them.

        Google Cloud Vision API key

        Handwriting transcription uses Google Cloud Vision. Your key is stored only in this browser (localStorage) and is sent directly to Google — never to any other server. In Google Cloud Console: enable the Cloud Vision API, then create an API key under APIs & Services → Credentials. The first 1,000 pages/month are free.

        Sync across devices (optional)

        Keeps notebooks in sync through a hidden app folder in your own Google Drive. In the same Cloud Console: create an OAuth client ID of type Web application and add this site's address under Authorized JavaScript origins. Paste the client ID here, save, and sign in when prompted. Then use the same ID on every device. The Mac app also needs the client secret (plus http://127.0.0.1:17987 under Authorized redirect URIs) so it can stay signed in; browsers can leave it empty.

        Chat (optional)

        💬 Chat answers questions about the open notebook. With an OpenAI API key it uses gpt-5.6-luna: fast, but each message is billed and the transcribed pages are sent to OpenAI — set a spending limit on the key. Leave it empty to keep everything on this machine instead.

        Without a key, chat uses a model running locally via LM Studio: in its Developer tab, load a model, start the server and enable CORS. Leave the address empty for the default http://localhost:1234.
